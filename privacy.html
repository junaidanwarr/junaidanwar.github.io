Privacy policy

Last updated: 5 October 2026

Who uses this app

yt-analytics is a private tool used only by the owner of one YouTube channel, to read that channel's own analytics. It is not offered to the public.

What it accesses

With the owner's permission, granted through Google sign-in, it requests two read-only scopes:

  • youtube.readonly: the channel's public details and its list of videos
  • yt-analytics.readonly: the channel's analytics reports (views, watch time, audience retention, traffic sources)

It cannot upload, edit or delete videos, comments or any other YouTube content.

Where the data goes

Data is downloaded to the owner's own computer and stored there. It is not sold, shared with third parties, or used for advertising. The sign-in token is stored only on the owner's computer.

Removing access

Access can be revoked at any time at myaccount.google.com/permissions. Deleting the local files removes all stored data.

Google API Services

This app's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
